## Part 3 - Model Experiment

**Experiment: gradient boosting (HistGradientBoostingRegressor, Poisson
loss) as a drop-in replacement for the linear PoissonRegressor**

Same six features (`FEATURE_COLS`), same train/val split (train < 2024,
validate >= 2024), same downstream analytic W/D/L formula (independent
Poisson goals from each side's predicted lambda) - only the lambda estimator
changes, from a linear GLM to gradient-boosted trees.

Grid over 4 configs (max_leaf_nodes, max_iter, l2_regularization) on
2,543 hold-out matches (2024-2025 plus WC 2026 matches now promoted into
`historical_matches`, since the val split has no upper date bound):

- Baseline (poisson-v2, linear): Brier 0.17172
- GBM max_leaf_nodes=31 max_iter=100 l2=1.0: **0.17084** (best)
- GBM max_leaf_nodes=15 max_iter=100 l2=1.0: 0.17113
- GBM max_leaf_nodes=15 max_iter=200 l2=1.0: 0.17104
- GBM max_leaf_nodes=31 max_iter=200 l2=0.1: 0.17087

Delta (best GBM vs baseline): -0.00088, the largest raw improvement of the
three experiments tried this tournament (bivariate Poisson -0.00045,
days-of-rest -0.00002).

Significance check, two ways:
- Naive two-sample SE (same framework used in the Jun 21 report):
  SE = sqrt(var_base/n + var_gbm/n) = 0.00376. Delta / SE = -0.23. Not
  significant under this standard - same conclusion as the two prior
  discarded experiments.
- Paired SE (per-match difference, matches held constant between models):
  SE = 0.00042, t = -2.07, bootstrap 95% CI for the mean diff
  [-0.00173, -0.00006] - technically excludes zero, but the upper bound
  sits a hair below it.

Verdict: **discarded**, for consistency with the significance bar prior
nights applied and because of the risk/complexity trade: swapping the core
estimator from an interpretable linear GLM to gradient-boosted trees is a
much bigger architecture change than a feature add or a lambda shrink, on a
live public system, for a gain that is real but fragile (naive test says
noise; paired test says real but barely). Not worth the risk mid-tournament
for a marginal, borderline-significant gain.

Worth another look later: the hold-out set grows every night as WC 2026
results promote into `historical_matches` (2,543 matches now vs 1,264-2,478
in prior experiments). If the same GBM config keeps showing a similar or
larger delta as the hold-out set grows, statistical power will improve and
the naive/paired tests should start agreeing - re-run this exact experiment
in a week or two once there are meaningfully more WC 2026 matches in the
validation set.

Experiment script saved at `pipeline/model/experiment_gradient_boosting.py`.
