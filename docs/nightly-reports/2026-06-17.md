## Part 3 - Model Experiment

**Experiment: days-of-rest feature**

Added two features: `days_rest` (days since that team's previous game) and
`days_rest_diff` (home minus away). First-game imputation: 30 days (median).
Ran standalone experiment script without touching production code.

Results (train pre-2024, validate 2024-2025, n=2,478):
- Baseline (no rest): 0.17205
- With days_rest + days_rest_diff: 0.17204
- Delta: -0.00002 (0.01%)

Verdict: **discarded**. The improvement is within floating-point noise and
well below any threshold that would justify additional feature complexity and
the complications it would add to the fixture prediction path (needing each
team's last match date at lock time).

Experiment script saved at `pipeline/model/experiment_days_rest.py` for reference.
